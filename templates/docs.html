Документация API v1.0.2

API проверяет DNS, соединение с TCP-портами и HTTP-ответ с сервера в России.

Запрос

Обязательный параметр target принимает домен, IP-адрес или HTTP(S)-URL.

GET {{ url_for('api_check_get') }}?target=example.com
POST {{ url_for('api_check') }}
Content-Type: application/json

{"target": "https://example.com/"}

Ответ

При валидном запросе API возвращает 200 и результаты проверок. Поле reachable показывает, удалось ли подтвердить доступность.

Поле http может быть null. Если сервер ответил по HTTP, поле http.ok равно true даже при статусе 4xx или 5xx.

Если цель не указана или невалидна, API возвращает 400 и объект с полем error.
